agentiik

Every step in its own container. Every run pinned to a commit.

Describe the graph in agentiik.yaml and git push it: each step runs in a fresh container, on your laptop or on a server your whole team shares, and a replay months later runs the very same commit.

Get started The roadmap GitHub

The graph and the file are one object. Ports sit where the YAML declares them, and selecting a step selects its block. The console as the documentation draws it, arriving in v0.6.0.

brick

Any image, any language

A brick is an OCI image with a manifest, and a script step runs in any image at all. Nothing outlives a step but what it wrote to its ports.

repository

Every workflow is a repository

agentiik.yaml at its root describes the graph. A push is validated before any branch moves, and a run keeps the commit it started from.

namespace

One installation, many people

Namespaces, groups and four roles decide who reads, runs and edits what, and a namespace you hold nothing in answers as one that does not exist.
